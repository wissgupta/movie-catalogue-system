# 🎬 Movie Catalogue System

A full-stack Java Spring Boot web application that lets users browse, search, and save their favorite movies using data from [The Movie Database (TMDb) API](https://www.themoviedb.org/).

---

## ✨ Features

- 🔥 Trending movie listings on homepage
- 🔍 Search for movies by title
- 🎥 Movie detail pages with trailer & reviews
- ❤️ Add/remove favorite movies (stored in H2 database)
- 📂 Genre-based browsing (Action, Comedy, Drama, etc.)
- 🌓 Light/Dark theme toggle with local storage support
- 📤 Export favorites as CSV
- 🧾 Modular Thymeleaf views (fragments, cards, etc.)
- 🎨 Netflix-style responsive frontend with Bootstrap 5
- 🧠 MVC architecture with Spring Boot, RestTemplate, and H2

## 🛠️ Tech Stack

- **Backend**: Java 17+, Spring Boot 3, Spring MVC, H2 Database
- **Frontend**: Thymeleaf, Bootstrap 5, JavaScript (theme toggle)
- **API**: [TMDb API](https://developers.themoviedb.org/)
- **Build Tool**: Maven
- **IDE**: IntelliJ IDEA
